## 💻 Na prática

Nesta seção serão registrados os códigos SQL desenvolvidos durante o curso.

### Cadastro de dados

Utilização do comando `INSERT` para cadastrar novos dados.

```sql
INSERT INTO ...
```

### Seleção de dados

Utilização do comando `SELECT` para consultar e visualizar dados.

```sql
SELECT ...
```

### Alteração de dados

Utilização do comando `UPDATE` para modificar dados existentes.

```sql
UPDATE ...
```

### Exclusão de dados

Utilização do comando `DELETE` para remover dados.

```sql
DELETE ...
```

> Os exemplos serão atualizados conforme eu desenvolver novos exercícios e práticas durante o curso.
